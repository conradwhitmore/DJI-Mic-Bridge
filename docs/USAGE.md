# 使用 MicBridge

## 连接与录音

将 Mic 2 与 Mac 配对，关闭其他接收设备。打开 MicBridge，选择发射器并连接。成功收流后，App 自动读取固件、首次电量；之后每120秒查询电量，失败时停止本会话的自动查询。高级诊断中的“读取 TX 电量”可手动重试，并重置120秒计时。

音频检测区显示 SPP 电平。“测试音频”中的录音操作保存 WAV；停止保存不会重开或关闭 SPP。HFP 输入可用且没有 SPP 时，也可以从此处测试普通蓝牙录音。HFP 首次输入存在约3–4秒唤醒现象，目前没有启用常驻保活。

## 作为系统麦克风

安装 MicBridge Audio 后，每次 SPP 收流或重连恢复时，App 自动向驱动输出并设为 macOS 默认输入。其他软件也可显式选择 MicBridge Audio；“设为系统输入”保留为手动重试入口，已选中时隐藏。已有 BlackHole 2ch 可作为兼容目标。

App 会锁定非 DJI 默认输入、输出及提示音路由，但其他应用仍可直接指定 DJI 端点。不要通过系统声音输入电平或 QuickTime 麦克风选择器检查正在使用 SPP 的 DJI 输入；这可能启动 HFP 音频并冲突。播放测试录音应选择真实扬声器或耳机，不能选没有扬声器的 Mic 2 输出。

## 按键映射

连接键、电源键和录音键分别绑定回车、Fn 或自定义组合键。映射保存在本机，按设备区分。发送系统快捷键需要在 macOS 中允许辅助功能；即使未设置映射，收到独立事件仍会让对应图标与箭头同步短暂亮蓝。

V2 使用 `04/68` 独立按键事件。卡片右上角“启用映射”按设备记住选择，默认开启，并在 SPP 连接或重连后自动应用。开启后短按只上报热键事件，不再执行原来的连接、降噪或本地录音操作；长按电源仍能关机。关闭开关会等待退出按键模式的成功应答，恢复普通按键功能，SPP 收音继续。

当前模式指令限实测固件 04.05.02.31。若发射器正在本地录音，先停止再开启热键模式。重启发射器会清除临时按键模式；App 重新连接后按已保存的选择重新应用。Fn 的系统动作是否接受模拟事件取决于 macOS 和目标应用。

设备卡片的“降噪模式”可独立切换，支持与热键模式同时使用。写入前读取配置，收到 ACK 后回读确认，并保留其他设置。V2 不提供振动开关；降噪切换沿用设备现有的振动反馈设置。

只有音频正常却没有按键反馈时，先在高级诊断检查控制包和按键状态包计数。`02/FF` 仍用于控制通道就绪检查、普通模式下降噪状态刷新和诊断，不再触发快捷键。状态包缺失可能阻塞初始查询和进入热键模式；退出临时按键模式不以收到 `02/FF` 为前提，但仍需可用的 SPP 通道。仅有音频电平不能证明控制通道就绪。

## 退出与恢复

关闭主窗口只隐藏窗口，App 继续驻留菜单栏。日常继续使用 MicBridge 时，也可直接关闭 Mic 2，下次开机由仍在运行的 App 恢复连接。

SPP 连接期间从菜单退出会提供两个选项：

- **仅本次退出**：先退出临时按键模式并确认应答，再保存录音、关闭本地通道并退出 App，不发送 `12/65`，保留发射器重连信息。App 退出后不再收音或监听按键；这不代表已恢复 HFP。
- **不再使用，恢复普通麦克风**：先恢复普通按键功能，再发送 `12/65`，收到匹配且校验通过的 `ACK 00` 后关闭 SPP 并退出，同时抑制自动重新进入。

“断开设备”仍执行第二种模式切换，但保留 App 运行。需要普通蓝牙收音时，建议随后将 Mic 2 关机再开机。没有 SPP 会话时，退出 App 不发送模式切换命令。

## 权限与数据

- 蓝牙：识别已配对发射器并建立 SPP。
- 麦克风：仅普通 HFP 测试录音使用系统输入采集。
- 辅助功能：仅用于发送用户配置的快捷键。
- 登录项：设置中由用户配置。
- 管理员授权：安装系统音频驱动时需要，日常 App 操作不需要。

连接日志在 `~/Library/Application Support/MicBridge/Connections/`；录音位置以 App 设置为准。日志可能包含设备地址和控制回复，公开反馈前需脱敏。App 不会自动上传这些文件。
