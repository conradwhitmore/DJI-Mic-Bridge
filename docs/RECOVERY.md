# 连接与恢复

## 日常退出

继续使用MicBridge时，可让App常驻并直接将Mic 2关机。从菜单退出选择“仅本次退出”会先恢复普通按键功能并确认应答，再关闭本地通道、保存录音，不发送12/65，也不表示已恢复HFP。

需要普通麦克风时，点击“断开设备”，或退出时选择“不再使用，恢复普通麦克风”。程序抑制自动SPP重连，先退出临时按键模式，再发送12/65，收到匹配ACK00后关闭通道。关闭主窗口只隐藏窗口，不退出菜单栏App。

已经实测能够退出SPP并恢复普通HFP录音，但恢复可能伴随蓝牙短暂断连。需要普通蓝牙录音时，退出后将Mic 2关机再开机是目前较稳定的方式。

## 收音中断或反复断连

1. 停止其他软件对DJI原生输入/输出的直接使用；选择MicBridge Audio作为输入。
2. 从App尝试正常断开，查看高级诊断和连接日志。
3. 如控制通道不可用、退出无法完成，关闭Mic 2，等待App观察到链路结束，再退出或重开App。
4. 重新开机，确认蓝牙连接后再进入SPP。不要并行运行Demo与MicBridge。

没有状态包时，音频可能仍有电平，但初始查询和进入热键模式可能不可用；退出临时按键模式仍可在通道可用时尝试。不要将音频存在视为控制链路健康，也不要将所有rxBuf日志直接认定为其他App抢麦。

## 工具边界

系统重置、删除蓝牙缓存或配对信息不是日常恢复步骤。`scripts/diagnostics/`中的历史研究/重置工具独立于App，不由App或CI自动运行；部分会修改系统或影响所有蓝牙设备，使用前应阅读源码及参数。不要用重置代替最小故障复现。
